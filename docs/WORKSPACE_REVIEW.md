# Workspace visual review criteria

The application is ready for visual acceptance only when:

- the main column is visibly centered at 1366px and 1440px widths;
- side gutters remain present at 1024px;
- Source and Destinations read as one continuous workspace;
- selected channels remain light and understated;
- the command footer aligns exactly with the workspace edges;
- Review does not introduce a third column until the viewport exceeds 96rem;
- controls remain readable without mixed tiny and oversized text;
- no landing-page hover lift, shimmer, pulse, or floating behaviour appears inside `.app-shell`.
