# Landing page product-truth contract

The public landing page must sell the product direction without presenting roadmap architecture as shipped functionality.

## Available now and safe to present as real

- Manual browser-local `ContentSignal` capture at `/signals`.
- Signal edit, snooze, ignore, archive, restore and browser refresh/reopen recovery.
- Manual Studio/Create path using explicit source context.
- Real configured model-provider generation routes where the active deployment can reach them.
- Destination-specific editable drafts, current editing/versioning rules, browser-local campaign recovery and current exports.

## Product direction that must remain visually/textually marked as future/building

- automatic event/signal detection;
- explainable ContentOpportunity ranking;
- automated angle selection and `Something else…` judgment flow;
- automatic media-format recommendation;
- image/carousel/video production through the target media contracts;
- full editorial planning and durable scheduling;
- long-lived narrative/style memory;
- Private Hybrid and Local Only end-to-end inference where not yet implemented;
- unattended full-pipeline publishing.

## Landing principle

The page should make the user understand the product emotionally before explaining architecture. Visual hierarchy should communicate this sequence:

1. **Stay in the work.** SignalFlow exists to reduce content operations around real work.
2. **Capture is already useful.** A thought can become a durable Signal without AI or a Campaign.
3. **Create is already useful.** Explicit intent can still use the current Studio path.
4. **The permanent system grows from Signal to judgment.** Future layers must be labeled as building/product direction until their issues close.
5. **Trust is behavior.** Approval, privacy and the option to produce no content are product rules, not marketing disclaimers.

The landing page must remain responsive, keyboard-visible, reduced-motion aware and truthful as capabilities change. When a roadmap capability becomes real, update both the capability matrix and this landing contract before changing public claims.
